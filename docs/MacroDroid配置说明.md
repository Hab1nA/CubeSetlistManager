# MacroDroid 翻谱配置说明（平板侧，首次使用约 10 分钟）

> 电脑端已把翻谱命令经 HTTP POST 发到平板 `IP:8766/turn`，body 为
> `{"x": <像素>, "y": <像素>, "count": 1|2}`——x=屏幕宽 25%（上一页）或 75%
> （下一页），y=屏幕高中点，count=2 表示双击（两次点击间隔约 100ms）。
> 坐标由电脑按平板上报的**物理分辨率**算好下发，MacroDroid 侧零坐标配置。

## 前提

- 平板已连电脑热点，浏览器打开 `http://<电脑热点IP>:8765`，在「翻谱设置」
  面板完成本机认领（名字/槽位/单击或双击）；
- 安装 **MacroDroid**（Play 商店免费版即可；5 宏上限对我们够用）；
- 谱面 App 保持前台、平板保持常亮解锁（锁屏下点击无效）。

## 配置步骤

1. **授权无障碍**：系统设置 → 无障碍 → 已安装的服务 → MacroDroid 开启
   （Gesture 点屏靠它，无 root）。
2. **关电池优化**：系统设置 → 电池 → 不受限制/关闭优化（防止切后台被杀）。
3. **新建宏**：MacroDroid → 宏 → + →
   - **触发器**：宏操作 → **HTTP 服务器请求**；
     首次会提示启用服务器：端口填 `8766`（与电脑设置页「翻谱接收端口」一致）；
     请求体选「**保存到字符串变量**」（命名 `body`），同时勾选
     「**解析 JSON 存入字典**」（命名 `d`）——解析后 `%d.x`、`%d.y`、
     `%d.count` 直接可用（不同版本措辞略有差异，认准 body/JSON 字样）。
   - **动作 1**：设备操作 → **手势(Gesture)** → 类型「点按(Tap)」，
     坐标填 `%d.x,%d.y`（或按提示分别填 X=`{d.x}` Y=`{d.y}`）。
   - **动作 2（仅双击设备）**：If/条件 `%d.count = 2` → 「等待」30ms →
     再加一个相同 Gesture 点按。单击设备跳过本步。
   - 宏名建议「翻谱」。
4. **核验收包（重要）**：先在动作 1 前加一步「提示(Toast/Flash)」文本
   `{body}`，从电脑网页「翻谱设置」面板点「测试下一页」，看弹出的内容
   是不是 `{"x":...,"y":...,"count":...}`；弹不出就是触发器没生效
   （端口/无障碍/电池优化逐项检查）。核验通过后删掉这一步提示。
5. **实测**：谱面 App 保持前台，电脑网页「测试上一页/下一页」→ 谱面
   应在左/右半区被点击翻页。

## 常见问题

- **宏没触发**：端口不一致（默认 8080，须改 8766）、无障碍没开、
  电池优化杀后台、平板息屏（锁屏下点击无效）；
- **点击位置不对**：确认「翻谱设置」面板里的屏幕分辨率是平板**物理**
  分辨率；必要时开发者选项开「指针位置」核对；
- **双击变两次单击**：确认动作 2 的 If 条件包住了「等待+第二次点按」，
  且「翻谱设置」里翻页方法选了「双击」；
- **换网络后不触发**：平板 DHCP 换 IP 后需在网页「翻谱设置」重新认领。
