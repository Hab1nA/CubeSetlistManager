# 配置参考

`config.json` 全字段说明（exe 同目录；样例见仓库根 `config.example.json`）。
多数项可在设置页改，本表供手改与排障。产品功能见 [README](../README.md)。

| 段 | 字段 | 说明 |
|---|---|---|
| obs | host / port / password | obs-websocket 地址（OBS 内置服务器需启用；password 留空时自动读 `%APPDATA%\obs-studio\global.ini` 的 [WebSocketServerSettings] ServerPassword，显式填写优先） |
| obs | obsExe / autoStart | OBS 未运行时自动拉起 |
| obs | mediaInput / videoRoot | 媒体源名=A 源（缺源自动补建；B 源自动派生为「名称 B」做无黑闪 A/B 换切，改名后旧源对自动清理）/ 视频库根目录 |
| obs | vjMute | VJ 静音播放：勾选=静音+关监听；不勾=开监听「监视器并输出」（设置页可改，默认勾选） |
| obs | retrySec / healthSec | 重连周期秒（默认 5）/ 探活周期秒（默认 30；只影响断线发现速度，一般勿改） |
| obs | videoLoops | VJ 视频循环标记表（程序自动维护，勿手改） |
| obs | videoDefault | 默认回落 VJ 槽位号（程序自动维护，勿手改）：其它视频播完后自动循环该槽位填画面 |
| obs | projectorMonitor | VJ 显示位置屏名（空=不投影），设置页可改 |
| daw | （顶层） | 底座选择：`cubase`（默认）或 `studioone` |
| dawSettings | dawExe / projectsRoot | **按底座嵌套**：`dawSettings.cubase / .studioone` 各持 dawExe/projectsRoot（旧平铺键只迁给 config 顶层 `daw` 键所指的活跃底座）；DAW 路径、工程库根目录（`<队伍>/<歌>/<歌>.cpr`，Studio One 为 `.song`）。切歌时 Cubase 经保存对话框恒保存、Studio One 丢弃未存修改，切歌前自行保存 |
| juno | inHint / outHint / inDev / dev / patchCh / perfCh / deviceId | JUNO-DS MIDI 端口提示与通道；dev=同名端口序号（两台同型号无线 MIDI 盒时在「键盘自动化」窗下拉选择，0 基，一般勿手改）；inDev=录制输入口（键盘自动化窗选过才落键，勿手改） |
| ax09 | inHint / outHint / inDev / ch / dev / ax | AX-09 USB MIDI 端口提示与接收通道（默认 1；琴上 SHIFT+V-LINK 连按 4 次到 Ch 页可查改）；dev/inDev 同 juno；ax=程序内部后端分派标记（勿手改） |
| pedal | deviceHint / bindings / hidBindings / hidDeviceHint / intercept / gestures / doubleWindow / longPress | 踩钉：MIDI 设备名提示与动作→CC、HID 动作→虚拟键码、所选设备身份与拦截开关、动作→手势（single/double/long，「学习」时踩出即自动分类）、双踩窗与长踩阈（默认均 0.35s） |
| pedal | remoteEnabled | 允许平板转发踩钉（踩钉控制页开关持久化；APP 侧另有「踩钉转发」开关，双开生效） |
| webRemote | enabled / mode / ip / serverPort / appPort / taskerPort | 移动端遥控总开关 / 服务网络（hotspot=自动开热点 / lan=用现有局域网）/ lan 模式服务网卡 IP / 网页 8765 / APP 8767 / 翻谱 8766 |
| webRemote | midiIn / devices | 翻谱信号 loopMIDI 端口名；已认领翻谱设备表（APP 网页认领自动维护，翻页方法存 APP 本机，勿手改） |
| webRemote | authToken / hosts | 可选配对令牌与 Host 白名单：authToken 非空时非回环请求须带令牌（`X-Cube-Token` / `Authorization: Bearer` / `?t=` / Cookie），页面经 `?t=` 打开时服务端种 `HttpOnly; SameSite=Strict` Cookie；hosts 只放显式列出的域名，挡 DNS rebinding；两者默认空=行为与旧版一致 |
| scoreServer | enabled / url / token / note / bars | 谱面服务器（目前是 drum-transcriber 房间）启动信号：DAW 在起点前 `bars` 小节画启动音符 `note`（默认 D2=50，走 webRemote.midiIn 翻谱信号口，需移动端遥控已启用），到达即 `POST <url>/api/room/cue?bars=&song=<当前歌名>`（头 `X-Room-Token: token`），对端从收到那一刻数 `bars` 小节预备拍后从该歌起点进；切歌完成时先发 `/api/room/song` 预载。歌名按对端曲库宽松匹配，对不上日志会报「被拒（404）」。暂无设置页，手改 config 后重启生效 |
| topMost | （顶层） | 主窗口置顶（默认开） |
| vjPortHint / kbPortHint | （顶层） | VJ 与键盘自动化的 loopMIDI 端口名提示（设置页可改，保存即热切换监听；空串=停用该联动） |
| clockPortHint | （顶层） | MTC 时码接收端口；空串=停用（走带三态/已播/自动推进不可用）。DAW 侧勾选：Cubase 在「运行控制 → 工程同步设置 → MIDI 时码目标」勾该端口（定位点另需「机器控制」页勾 MMC Slave Active）；Studio One 在「歌曲选项 → 同步」勾 MIDI 时码输出；Studio One 定位点另需「选项 → 高级 → 同步」勾同步到外部设备并把 MIDI 时间码源选为直控口 |
| mrPortHint | （顶层） | MIDI Remote 直控口名提示（双底座共用同口同 CC 表；默认「CubeSetlist Remote」），部署见 README「快速开始」第 4 步 |
| launchAppsOnStart | （顶层） | 「启动时自动打开被控软件」勾选持久化 |
| exitCloseApps | （顶层） | 「退出时关闭被控软件（DAW/OBS/loopMIDI）」勾选持久化；关闭顺序 DAW → OBS → loopMIDI，保存框按默认钮保存、OBS 走 WM_CLOSE 不强杀 |
