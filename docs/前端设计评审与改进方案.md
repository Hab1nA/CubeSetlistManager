## 八、批次 F：交互完善与打磨（P1 余项 + P2）

按价值排序，P2 项可按余力取舍：

1. **主控台运行反馈**（P1）：`/cmd` 对「服务未就绪/互锁忽略/已排队」目前只写日志且仍返 200——响应体带 msg 回 toast，或主控台页加最近 1-2 条日志浮动条（全停核验告警同理）。
2. **断连指示**（P1）：poll 连续失败 ≥3 次→状态栏「连接中断…重试中」常驻标识，恢复即灭（现 9 处 `catch{}` 全静默）。
3. **键盘可达性与快捷键**（P1）：空格=智能三态钮；列表行 tabindex+Enter=切歌；`.go-switch` 的 `visibility:hidden` 改 `opacity:0`（visibility 会把按钮踢出 Tab 序）。
4. **素材库交互**（P1/P2）：空态+「去设置工程库根」引导；行单击改「仅选中」，＋为唯一加入入口（旧版防误触是双击）；（P2）多选批量加入。
5. **拖拽细节**（P2）：pointerup 未进 dragstart 复位 draggable；拖到行外落空给反馈。
6. **toast**（P2）：err 延长至 5s 或手动关；日志过滤「仅错误」实际保留 warn——改名或改选择器。

## 十、约束与风险（两轮累积，执行者必读）

- **零构建链**：vanilla 三件套（index.html/app.css/app.js），不引 node 工具链/框架/图标库；图标手写 SVG。
- **线程模型**：pywebview 6.x 强制主线程 → Tk 业务栈在专属子线程；新增后端端点的状态读写必须经 calls 队列投递（沿用 `_*_get_web`/`_*_apply_web` 镜像模式，setlist_gui.py:1739 起），跨线程直改是被审计过的雷区。
- **轮询节拍**：/state 500ms 是全局节拍器，动效时长避开 500ms 及谐波（120/160/200/240/300）；差量/增量更新避免轮询重建 DOM 打架。
- **手势契约**：`gestures` = 动作→{single,double}；六项动作枚举见 pedal.py:43-44；`_pedal_apply_web` 必须校验（C3）。
- **音名口径**：仓内标准 C4=60（JUNO 槽 60-69、AX 72-77 已按此）。
- **文案**：沿用 `ui_text.py` 与《UI文案与信息设计规范.md》口径；底栏提示不加「？」前缀那类规范仍有效。
- **探针教训（两条）**：① probe_ui 的 fetch 拦截桩必须嵌套安全（__fetch0 只记真 fetch+模式切换），桩泄漏会伪装成后端故障；② 只查 DOM 属性会漏计算样式问题（[hidden] 打穿就是这么漏的）——断言要下到 getComputedStyle 层。
- **WebView2 缺失兜底 / 渲染失败兜底 / CUBE_TK=1 回退**：既有链路不得破坏。
- **测试口径**：flake 验证以多轮裸跑全量为准（历史教训，见 test_pedal_wire 治理记录）。

- **定案**：pywebview（WebView2）+ Web 前端，桌面窗/平板遥控/安卓 APP 收敛为一个 UI 栈。
