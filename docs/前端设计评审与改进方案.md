### 共通规则定案（先立规矩，后改页面）

**C1 字体规范**（字阶沿用 :root token，新增映射与禁则）：
- 页面标题 h2 = `--f-xl` 22px 700；卡题 h3 / md-head / colhead = `--f-md` 15px 700；
  状态大字 stat-big = `--f-lg` 700；正文与表单控件 = `--f-md`；次级说明 = `--f-sm`；
  标签/徽标 = `--f-xs`。清除游离字号（h2 的 20px 字面量）。
- 粗体只用于：标题、.lbl、stat-big/stat-pair 数值、当前行曲名、导航选中态。正文不加粗。
- 颜色：fg=正文与标题；dim=次级与未接；ok/warn/err 只进状态组件（灯/徽标/状态值/
  危险钮）；accent 只用于选中态、焦点、地址文本。演出模式大字号（46/72）为显示级
  特例，不进常规字阶。
- 卡头与内容区间距统一 = 卡内边距（16px）：`.card h3`、`.md-head` 的
  margin-bottom 统一 `--s4`（对应 N1/N2 的「行距=上边距」原则，全局一致）。

**C2 提示文字规范**（奥卡姆：如无必要，勿增实体）：
- 图标钮的 title=控件名（必需，兼作无障碍名）；文字钮不设与标签同义的 title。
- 机制类提示（非直觉行为）≤30 字，只出现一次：优先悬停，其次卡头 h3-note 或
  页脚注；同一信息不得两处并存。
- 页脚注一句话；空态一句话+一个动作。已直觉可用的功能不写说明。

**C3 空格规范**（终结混乱）：
- 中文与英文/数字之间一个半角空格（如「10 键」「CC 74」「192.168.1.5:」）。
- 纯中文词之间不加空格；「·」分隔符两侧各一个半角空格；序数短语（第2口）不加空格。
- flex+gap 的标题行内不再写字面空格（gap 已承担间距）。

**C4 页面标题一致性**：定案=页面标题与侧栏标题完全一致。键盘自动化→「键盘」、
VJ 联动→「VJ」；主控台为驾驶舱布局无页题（结构性例外）。

## 二、约束与红线（历轮累积，执行者必读）

- **零构建链**：vanilla 三件套（webapp/），不引 node 工具链/框架/图标库；图标手写 SVG。
- **线程模型**：新后端端点/状态读写必须经 calls 队列（`_*_get_web`/`_*_apply_web`
  镜像模式）；跨线程直改是被审计过的雷区。
- **轮询节拍**：/state 500ms 全局节拍器；动效时长避开 500ms 及谐波；差量更新
  防轮询重建打架（dataset.sig 家族）。
- **文案**：沿用《UI文案与信息设计规范.md》+ 本轮 C2/C3 增补；全角标点；禁全角括号。
- **探针教训**：fetch 桩嵌套安全；断言下到 getComputedStyle 层；css 修复必须
  getBoundingClientRect 逐项实测（「看图猜」两次翻车记录）；同特异度后位覆盖
  必查后文。
- **WebView2 缺失兜底 / CUBE_TK=1 回退 / 平板旧页（PAGE_BROWSER/PAGE_APP）**：
  既有链路不得破坏。
- **测试口径**：flake 以多轮裸跑全量为准。
- 底线：不动 main、不打 tag、不发版、不删测试、运行时真实数据不入库。
