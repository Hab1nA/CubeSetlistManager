# M0 验证清单（演出前必读）

> 本清单固化了只存在于开发记忆里的待验证项与现场操作知识。演出不可重来，
> 每次大改后、正式演出前，逐项打勾。

## 一、赛前自检（演出当天，约 5 分钟）

- [ ] 双击 `Cube Setlist Manager.exe`，观察监控栏：loopMIDI 端口=就绪、OBS 状态=已连接、
      MIDI 监听=监听中（三项应全绿）
- [ ] 日志区无红字（loopMIDI 未就绪 / MIDI 监听未启动 / 启动失败）
- [ ] 播放列表时长列无红色「未知」（有则当场手填，否则该曲自动切换不生效）
- [ ] 点列表任意一首双击切换一次：工程正常关→开，NOW 横幅更新
- [ ] 「开始」→ 走带跟随=播放中，NOW 横幅剩余时间在倒计（开了时钟的工程）
- [ ] OBS 外屏投影正常：发一个测试音符（`python midi_bridge.py --send 60`）视频起播
- [ ] 踩钉：踩钉控制窗口状态=监听中；逐个绑定实踩一遍，对应按钮动作生效
- [ ] 键盘自动化：窗口「触发」按钮发送成功（琴上音色切换、最近切换=绿色）
- [ ] 全停按钮：走带停止 + OBS 熄屏
- [ ] 离线自检（改过代码后必做）：`python test_bridge.py` 通过
- [ ] 移动端遥控（如当日使用）：设置页状态行=热点已开；平板已连且网页能打开
- [ ] 翻谱 APP（如当日使用）：打开 Cube Remote 自动直连进控制页；通知栏
      「翻谱接收中 · 端口 8766」在列；无障碍图标=开启

## 二、现场故障恢复路径

| 症状 | 处置 |
|---|---|
| 声音需要立刻停 | 主界面「全停」按钮 / 踩钉「全停」（向所有工程窗口发停止+熄屏） |
| 切歌卡在「切换中…」 | 等待 ≤120s 自动报失败；看日志：未知弹窗标题会记出来，人工处理后重试下一首 |
| OBS 崩了 / 视频黑 | 桥自动重连并自动拉起 OBS（约 10-30s）；期间音符触发只记失败不阻塞歌曲流程 |
| Cube Setlist Manager 崩了 | 重启 exe：按 Cubase 窗口标题自动恢复当前曲目/音色映射/时长；视频会短暂失联，桥若是独立 exe 则不受影响。崩溃栈在 exe 同目录 `crash.log` |
| Cubase 弹「未找到端口」等模态框 | 程序自动仿人回车放行；若日志出现「未知弹窗（不按键）」需人工点掉 |
| 误切歌 | 双击非当前项默认弹确认（设置页「切换工程需确认」可关）；点「否」即无副作用。已切走则再双击切回来 |

## 三、待真机验证项（M0，改一次验一次）

- [ ] **两段式自动切换**：工程播满时长 → 日志出现「自动停止走带」→ 停止生效后自动切下一首；
      停止键未送达时 3 秒重试（至多 3 次）是否有效
- [ ] **自动切换与手动切歌竞争**：切换瞬间手动双击另一首，行为是否符合预期（自动切换会让位）
- [ ] **暂停键序**（ESC+NUM0）：停止态误按「暂停」是否还会触发 Cubase「双击停止」
      跳回上次起播位置（新版按钮已自动禁用，验证禁用逻辑本身）
- [ ] **继续键序**（ESC+SPACE）：停止态按「继续」从光标处起播、不回零
- [ ] **弹窗文案校准**：实际遇到「保存/激活」类弹窗的标题与 `cubase_ctrl.DIALOG_ENTER_MARKS`
      是否命中（不命中会记「未知弹窗」，按实际文案补充标记）
- [ ] **踩钉**：学习捕获（USB 直连 + 经 Rubix24 DIN 两种接法）、上升沿实踩、150ms 去抖手感、
      拔插后 10 秒自动重连
- [ ] **JUNO-DS**：设备 ID 是否 17（现配 16）、Favorite TX 是否真发 BS/PC（需 V2 固件+
      System→MIDI→Tx Favorite TX 开启）、Performance 切换被 perfCh=16 接受、
      模式 SysEx 推断（85→PERFORM / 86/87/92/93→PATCH / GM→GM1）实琴验证
- [ ] **AX-09 Lucina**（首次接琴必做，按顺序）：
      ① USB 接入后看监控栏/键盘自动化窗口「AX 输入/输出」是否 ✓；端口名不含
      "AX-09"（可能叫 Lucina）就改 config ax09.inHint/outHint
      ② 琴上开 Bn 发送：SHIFT+V-LINK 连按 5 次 → INC/+ 选 ON → SHIFT+WRITE 保存；
      接收通道确认=1（SHIFT+V-LINK 连按 4 次的 "Ch"）
      ③ 窗口录制一个 AX 槽位→「触发」→ 琴上面板音色应跟随切换
      ④ **Bank Select 接收存疑项**：官方图表标 "*1 O（可选）"但面板无对应开关；
      实测 LSB=1 的音色（GUITAR/BASS 组 9-24 号，即音色 129-144）能否到达——
      到不了就只把 1-128 号音色划给自动化槽位
- [ ] **窗口置顶**：勾选状态下双击切歌/走带时 Cube Setlist Manager 不被 Cubase 盖住；走带键发完后
      直接在搜索框打字，字符落在搜索框而不是 Cubase（空格没有误停走带）
- [ ] **无时钟工程**：未开发送 MIDI 时钟的工程，视频触发正常、走带跟随显示
      「未启用（未收到时钟）」、暂停/继续按钮保持可用
- [ ] **移动端遥控·热点**（首次必做，按顺序）：设置页勾「启用移动端遥控」保存 →
      ① 非管理员权限热点能开（状态行显示 SSID/密码/IP）；
      ② 平板连热点后浏览器访问 `http://<状态行IP>:8765`，Windows 防火墙首次
      放行弹窗处理过（允许一次）；
      ③ **完全无网络场景**：本机无任何已连接网络时热点能否开启（预期报错
      「先连任意网络」；实测结果记到本项）；
      ④ 热点空闲自动关闭的实际时限；「热点已开、平板已连」纳入演前检查
- [ ] **移动端遥控·网页**：网页播放/暂停/继续/停止/回零/上一首/下一首/全停与
      桌面行为一致；点歌单行切歌的网页内确认弹窗（switchConfirm 开时）；
      切换中按钮禁用、NOW/NEXT 冻结显示切歌前歌名（状态行显示「切换中…」）；
      切后台 30 分钟回前台状态恢复、连接徽标 RESYNC
