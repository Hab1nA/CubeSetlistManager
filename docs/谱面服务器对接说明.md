# Cube Setlist Manager × 谱面服务器 对接说明

谱面服务器目前是鼓手电脑上的 drum-transcriber（下文简称“谱面这边”）。

## 这是做什么的

演出时 DAW 放每首歌的工程，谱面这边要跟 DAW **同时进歌**。做法是：DAW 每首歌里提前 2 小节放一个“启动音符”，Cube 收到后发一个 HTTP 请求给谱面这边。谱面这边从收到请求那一刻开始数 2 小节预备拍，数完从这首歌的起点开始播谱面，跟 DAW 同时进。

Cube 的实现在 [score_server.py](../score_server.py)。接进业务的地方：`web_remote.py` 收翻谱音符的分流、`setlist_gui.py` 的切歌收尾/启动恢复/手动跟随（游离时清歌名）与设置页保存（改完即生效）。

## 1. 启动音符：用什么音、放在哪

- **音符**：D2，MIDI 音符号 50。它和翻谱用的音不冲突：翻页是 48/49，设备槽位是 72–81，VJ 用的 48 和 72–102 也都不是它。
- **走哪个口**：和翻谱音符同一个 loopMIDI 口，就是设置里“翻谱信号”选的那个口（`webRemote.midiIn`）。可以在翻谱那条 MIDI 轨上直接加这个音，或者另开一条轨输出到同一个口。
- **放在哪**：每首歌里，**大家一起进的那个小节往前正好 2 小节的第一拍**。比如乐队从第 5 小节进，音符就放在第 3 小节第 1 拍。
- **音符长度、力度、通道都无所谓**，只要是 Note On、力度大于 0 就行。
- “大家一起进的小节”谱面这边也会每首歌标一份（演出模式里的“起点”）。如果工程有前奏空白、弱起、count-in 之类，两边要对一下每首从第几小节进，保持一致。

## 2. 信号怎么变成 HTTP 请求

这一步 Cube 会自动做。设置页「谱面服务器」卡填写后保存即生效（无需重启）；也可以直接改 `config.json` 的 `scoreServer` 段后重启 Cube（字段同下）：

```json
"scoreServer": {
  "enabled": true,
  "url": "http://<谱面电脑的 IP>:8765",
  "token": "<房间 token，鼓手提供>",
  "note": 50,
  "bars": 2
}
```

Cube 实际发出去的请求是这样的：

| 什么时候发 | 请求 |
|---|---|
| 切歌完成（工程打开好了） | `POST http://<IP>:8765/api/room/song?song=<歌名>`：让谱面这边先把这首歌加载好 |
| 收到启动音符 | `POST http://<IP>:8765/api/room/cue?bars=2&song=<歌名>`：从收到这一刻开始数 2 小节，然后进歌 |

- token 由 Cube 放在请求头 `X-Room-Token` 里（谱面服务端另认查询参数 `&token=…`，但 Cube 不发这一种）。
- `song` 用的是 Cube 曲库里的歌名，也就是工程文件夹的名字。谱面这边按曲库标题宽松匹配：前面的编号、标点、大小写、全半角不用完全一样，能唯一对上就行。
- `bars` 必须等于 DAW 里提前的小节数。如果想改成提前 1 小节，DAW 里的音符位置和这里的 `bars` 要一起改。
- 启动音符不等翻谱的 100ms 合并窗口，到了就发。每次都新建连接、失败不重发，免得谱面这边收到两次启动信号。
- 结果都会写进 Cube 的运行日志（设置页卡片「上次信号」同步显示最近一条）：
  - 「谱面服务器预载《xx》完成」
  - 「谱面服务器启动《xx》，预备 2 小节已送达，N ms」
  - 失败时会写「谱面服务器启动《xx》，预备 2 小节被拒 404：…」或者连接失败的原因。

## 3. 其他注意事项

- **移动端遥控要开着**：启动音符走的是翻谱信号口，这个口只有在移动端遥控启用、并且配了 `midiIn` 时才会打开。
- **歌名提前对一遍**：排练时把歌单从头切一遍，看日志里每首是不是都显示“预载完成”。出现 404 的就告诉鼓手，在谱面那边改标题或者加别名。
- **速度要一致**：谱面这边按它曲库里这首歌的速度数预备拍。如果工程和谱面那边的速度不一样，或者在启动音符和进歌之间这 2 小节里有变速、变拍号，就会对不上。有这样的歌要提前说。
- **网络**：两台电脑要在同一个网络里，尽量用路由器加有线，或者至少是稳定的 Wi-Fi。路上花的时间会原样变成谱面这边晚进的时间：有线只差几毫秒，可以忽略；如果是手机热点，或者网卡在省电状态，可能差几百毫秒。建议在路由器上给谱面电脑固定 IP，免得地址变了要改配置。
- **谱面电脑要开着工作区页面**：谱面和声音是由那个页面负责的。没开的话 Cube 日志会显示被拒（409）。谱面服务要用 `--host 0.0.0.0` 启动，别的电脑才连得上。
- **停止不会同步**：DAW 停下时，谱面这边不会跟着停，需要鼓手手动停。以后如果需要，可以加上“DAW 停止就通知谱面这边停”（`POST /api/room/stop`）。
- **重复触发**：如果把播放位置拖回启动音符前面再放，音符会再触发一次，谱面这边就会重新数拍、重新进，一般这正好是想要的效果。但如果某首歌中间会循环回到启动音符那里，要注意别重复触发。
- **还没在 Windows 上实测**：在 macOS 上用 Cube 的 `score_server.py` 对谱面服务跑通过，从发出请求到收到约 4ms，进歌的位置也对得上。但 Cubase 经 loopMIDI 进 Cube 这一段要在 Windows 机器上跑一遍才算数。建议排练时先拿一首有弱起的歌、再拿一首速度快的歌试。
