# Tasker 翻谱配置说明（平板侧，首次使用约 10 分钟）

> 电脑端已把翻谱命令经 HTTP POST 发到平板 `IP:8766/turn`，body 为
> `{"x": <像素>, "y": <像素>, "count": 1|2}`——x=屏幕宽 25%（上一页）或 75%
> （下一页），y=屏幕高中点，count=2 表示双击（两次点击间隔约 100ms）。
> 坐标由电脑按平板上报的**物理分辨率**算好下发，Tasker 侧零坐标配置。

## 前提

- 平板已连电脑热点，浏览器打开 `http://<电脑热点IP>:8765`，在「翻谱设置」
  面板完成本机认领（名字/槽位/单击或双击）；
- 安装 **Tasker**（6.x，Play 商店版）与 **AutoInput**；
- 谱面 App 保持前台、平板保持常亮解锁（锁屏下 AutoInput 点击无效）。

## 配置步骤

1. **给 AutoInput 授权无障碍**：系统设置 → 无障碍 → 已下载的应用 →
   AutoInput 开启。
2. **导入翻谱任务**：电脑网页「翻谱设置」面板 →「下载任务 XML」→
   Tasker → 底部「任务(TASKS)」标签 → 右上 ⋮ → **导入** →
   选下载目录里的 `turn-page-task.xml`。
   导入失败或 Tasker 版本较旧时，按下面第 3-5 步手工建同名任务「翻谱」。
3. **核验收包变量名（重要）**：Tasker 事件「HTTP Request Received」收到的
   请求体存在哪个变量随版本有差异（6.x 一般是 `%http_body`）。首测时先在
   任务里加一步「提示(Flash)」文本 `%http_body`，从电脑网页点「测试下一页」，
   看弹出的内容是不是 `{"x":...,"y":...,"count":...}`；不是就在事件配置里
   找对应变量（常见 `%http_request_body` / `%HTTPD`）替换。
4. **解析 body**：任务加「代码 → JavaScriptlet」，代码：
   ```js
   var o = JSON.parse(local('%http_body'));
   var x = o.x; var y = o.y; var n = o.count;
   ```
   （若上一步核验出变量名不同，替换 `%http_body`。）
5. **执行点击**：任务加「插件 → AutoInput → 手势(Gesture)」：
   - 手势类型：点按（Tap），坐标 `%x1,%y1` 填 `%x,%y`；
   - count=2 需双击：再加一个 30ms「等待」+ 第二个相同 AutoInput 手势，
     或用 AutoInput 手势的「两点轻击」写法（版本支持时）。
   count=1/2 的分流可用「任务 → If %n = 2」包第二下点击。
6. **建配置(Profile)**：Tasker → 配置 → + → 事件 → 网络 →
   **HTTP Request Received**：端口填 `8766`（与电脑设置页「Tasker 端口」
   一致），关联任务「翻谱」。
7. **关电池优化**：系统设置 → 应用 → Tasker 与 AutoInput → 电池 →
   不受限制（否则息屏后事件收不到）。

## 验证

电脑网页「翻谱设置」面板 → 本机设备卡 →「测试上一页 / 测试下一页」→
平板屏幕对应半区应出现点击效果（可先在开发者选项开「指针位置」看落点）。

## 跑通后（一次性）

Tasker 长按任务「翻谱」→ 导出 → 导出为 XML，把内容回填给开发者（或替换
本目录 `Tasker翻谱任务.xml` 与电脑端内嵌常量），后续新平板下载导入即用。

## 常见问题

| 症状 | 处置 |
|---|---|
| 电脑日志「翻谱推送失败（超时）」 | 平板休眠/Wi-Fi 掉了/电池优化没关；亮屏重试 |
| Toast 显示的 body 为空 | 第 3 步变量名不对，换事件配置里列出的变量 |
| 点击位置偏 | 平板网页「翻谱设置」重新认领一次（刷新分辨率） |
| 双击识别成两次单击 | 谱面 App 对双击间隔敏感；把第二次点击的等待调到 50-150ms |
