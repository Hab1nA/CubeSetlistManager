## 三、撤回的审计判定（复核后不成立）

| 原判定 | 撤回理由 |
|---|---|
| Q3「OBS 重连不重放 vjMute」半接线 | 前提不成立：obs_ctrl 连接循环在 `on_connected` 回调**之前**已 `_set_mute(ws)` 随每次（重）连同步静音（「静音偏好随每次连接同步」注释在案），apply_mute docstring 的「连接时也会同步一次」即指此处。回调里再加 apply_mute=重复 RPC，且 `_act` 失败会掐连接，静音失手会让同周期投影恢复陪葬。首轮已按此误判加过代码，对抗复审指出后两版撤回原状+删对应测试 |
| `mr_ctrl.available()` 死代码 | 诊断 API（docstring「探针/诊断用」），是 `_ensure_locked` 开口/冷却逻辑的唯一直接测试入口，`set_alive_probe` 文档引用其语义。保留 |
| config.example.json 缺 `juno/ax09.inDev` | kbd_auto 装载处 docstring 明说「选过才落键，不进 DEFAULT——装载处强建会废掉旧配置的 dev 跟随语义」。example 刻意不含，设计如此 |
| `/devices`、`/device/*` 五端点死接口 | 由后端内嵌移动页（安卓 WebView 加载）消费，活跃接口 |
| obs_ws 三个模块级函数「可改私有」 | 公开名实为内部件，改名零收益有漏改风险。不动 |
