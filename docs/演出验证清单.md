# 演出验证清单（演出前必读）

> 本清单固化了只存在于开发记忆里的待验证项与现场操作知识。演出不可重来，
> 每次大改后、正式演出前，逐项打勾。

## 一、赛前自检（演出当天，约 5 分钟）

- [ ] 双击 `Cube Setlist Manager.exe`，观察监控栏：loopMIDI 端口=就绪、OBS 状态=已连接、
      MIDI 监听=监听中（三项应全绿）
- [ ] 日志区无红字（loopMIDI 未就绪 / MIDI 监听未启动 / 启动失败）
- [ ] 播放列表时长列无红色「未知」（有则当场手填，否则该曲自动切换不生效）
- [ ] 点列表任意一首双击切换一次：工程正常关→开，NOW 横幅更新
- [ ] 「开始」→ 走带跟随=播放中，NOW 横幅剩余时间在倒计（开了时钟的工程）
- [ ] OBS 外屏投影正常：发一个测试音符（`python midi_bridge.py --send 60`）视频起播
- [ ] 踩钉：踩钉控制窗口设备行=监听中、绑定列表与预期一致（本页打开期间踩钉
      整体静音——核对完关页，再实踩逐个验证动作生效）
- [ ] 键盘自动化：窗口「触发」按钮发送成功（琴上音色切换、最近切换=绿色）
- [ ] 全停按钮：走带停止 + OBS 熄屏
- [ ] 离线自检（改过代码后必做）：`python -m pytest tests/` 通过
- [ ] 移动端遥控（如当日使用）：设置页状态行=热点已开；平板已连且网页能打开
- [ ] 翻谱 APP（如当日使用）：打开 Cube Remote 自动直连进控制页；通知栏
      「翻谱接收中 · 端口 8766」在列；无障碍图标=开启
- [ ] 射频链路（2026-10-02 演出全灭事故定案）：关键链路优先有线（MIDI→5-pin DIN、
      踩钉→有线 USB HID 踏板、翻谱→专用旅行路由器+网线）；当日若仍用任一无线链路，
      彩排必须满场或人体遮挡走位测试——空场全绿不可信（见 `舞台射频频段调研.md`）

## 二、现场故障恢复路径

| 症状 | 处置 |
|---|---|
| 声音需要立刻停 | 主界面「全停」按钮 / 踩钉「全停」（向所有工程窗口发停止+熄屏） |
| 切歌卡在「切换中…」 | 等待 ≤120s 自动报失败；看日志：未知弹窗标题会记出来，人工处理后重试下一首 |
| OBS 崩了 / 视频黑 | 桥自动重连并自动拉起 OBS（约 10-30s）；期间音符触发只记失败不阻塞歌曲流程 |
| Cube Setlist Manager 崩了 | 重启 exe：按 Cubase 窗口标题自动恢复当前曲目/音色映射/时长；视频会短暂失联，桥若是独立 exe 则不受影响。崩溃栈在 exe 同目录 `crash.log`；黑面/无响应排查看 `stall.log`（停摆时间线+队列现场）与 `stall_stack.log`（停摆瞬间全线程栈） |
| Cubase 弹「未找到端口」等模态框 | 程序自动仿人回车放行；若日志出现「未知弹窗（不按键）」需人工点掉 |
| 误切歌 | 双击非当前项默认弹确认（设置页「切换工程需确认」可关）；点「否」即无副作用。已切走则再双击切回来 |
